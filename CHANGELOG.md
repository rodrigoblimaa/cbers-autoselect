# Changelog

## 0.1.0 — first experimental release

- Rename to **CBERS AutoSelect** and reset version numbering before first publication.
- QGIS polygon AOI selector, configurable coverage/cloudiness thresholds and 2 m/8 m products.
- Automatic backwards STAC searches with pagination, chronological evaluation and INPE product identifiers.
- Raster-valid-pixel coverage and experimental potential cloudiness within the AOI.
- QGIS background task with progress messages and cancellation.
- Automatic English/Brazilian Portuguese UI and messages.
- Compact toolbar icon, GPL v2 license, documentation and standalone tests.

This release does not claim a validated cloud mask or cross-platform QGIS desktop testing.
